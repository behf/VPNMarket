## ⚙️ راهنمای نصب (جادوی تک-دستوری)

### پیش‌نیازها
*   یک سرور تمیز با سیستم‌عامل **Ubuntu 22.04**.
*   یک دامنه یا زیردامنه که به IP سرور شما متصل شده باشد.
*   دسترسی SSH به سرور با کاربر `root` یا دسترسی `sudo`.

### دستور نصب

وارد سرور خود شوید و دستور زیر را اجرا کنید. اسکریپت ما بقیه کارها را به صورت خودکار انجام می‌دهد!

```bash
wget -O install.sh https://raw.githubusercontent.com/behf/VPNMarket/main/install.sh && sudo bash install.sh
```

### نکات مهم برای نصب

1. **دامنه:** دامنه‌ای وارد کنید که به سرور شما متصل است (مثال: `vpnmarket.example.com`)
2. **دیتابیس:** اطلاعات دیتابیس را انتخاب کنید (نام، کاربری، رمز عبور)
3. **ایمیل SSL:** برای SSL خودکار، ایمیل معتبر وارد کنید
4. **SSL:** بعد از نصب، میتوانید SSL را فعال کنید

## 🔄 نحوه آپدیت پروژه

اگر پروژه را قبلاً نصب کرده‌اید، برای آپدیت به آخرین نسخه و دریافت قابلیت‌های جدید، **نیازی به نصب مجدد نیست!**

۱. از طریق SSH به سرور خود متصل شوید.
۲. وارد پوشه اصلی پروژه شوید:
   ```bash
   cd /var/www/vpnmarket
   ```
۳. دستور زیر را اجرا کنید تا اسکریپت آپدیت، آخرین تغییرات را دریافت و نصب کند:
   ```bash
   sudo git pull origin main && sudo bash update.sh
   ```

**توجه:** فرآیند آپدیت ممکن است چند دقیقه طول بکشد. در این مدت سایت شما در حالت "تعمیر" خواهد بود.

## 📋 نحوه استفاده از Sanaei با Bearer Token

اگر از **X-UI/Sanaei** استفاده می‌کنید:

1. به تنظیمات پنل Sanaei بروید: **Settings → Security → API Token**
2. توکن API را کپی کنید
3. هنگام افزودن سرور در VPNMarket، توکن را در فیلد **"توکن API (Bearer Token)"** وارد کنید
4. بیشتر دوا میدهد! ✅
